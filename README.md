# 📄 CV Resume Website

A clean, modern, and responsive **CV / Resume website** built using **HTML5, CSS3, Bootstrap 4.6, and Font Awesome 5**. 💻✨

This project presents a professional CV layout with a two-column design, including profile information, education, work experience, skills, hobbies, awards, references, and contact details. 👨‍💻📋

---

## 🌟 Features

* 👤 Profile photo and personal information
* 💼 Professional job title
* 📞 Contact information
* 🧠 Skills with visual progress bars
* ✈️ Hobbies with Font Awesome icons
* 👨‍🎓 Education history
* 🏢 Work experience
* 🏆 Awards and achievements
* 🤝 Professional references
* 📱 Responsive Bootstrap layout
* 🎨 Custom colors and typography
* 🔤 Custom local fonts

## 📋 Main Sections

### 👤 Profile

Contains a professional introduction and personal summary.

### 🎓 Education

Displays educational qualifications with corresponding years and descriptions.

### 💼 Work Experience

Shows previous work experience, company names, dates, and job descriptions.

### 🧠 Skills

Skills are represented using custom progress bars to visually show proficiency levels.

### 🎯 Hobbies

Uses Font Awesome icons to represent different hobbies and interests.

### 📞 Contact

Contains important contact information such as:

* 📍 Address
* 📧 Email
* 🌐 Website
* 📱 Phone number

### 🏆 Awards

Provides a dedicated section for professional or academic achievements.

### 🤝 References

Contains professional reference information.

You can easily customize the CV by changing:

* 👤 Name
* 🖼️ Profile picture
* 💼 Job title

* 🧠 Skills
* 📊 Skill percentages

For example:

```html

</h1>
```

Replace `Name Surname` with your own name.

## 📱 Responsive Design

The website uses Bootstrap's responsive grid system.

The main layout uses:

```html
col-lg-3
col-lg-9
```

🖥️ On large screens, the CV is divided into a **3/9 column layout**.

📱 On smaller screens, Bootstrap's responsive grid allows the layout to adapt automatically.
